# 🍽️ RecipeHub — Full-Stack Recipe Sharing & Commerce Platform

RecipeHub is a complete recipe sharing platform with role-based workflows for Admins, Sellers, and Users.

## 📂 Project Architecture

```
RecipeHub/
├── backend/          # Node.js, Express, TypeScript, MongoDB backend application
├── frontend/         # Next.js / React frontend application (to be built)
└── README.md
```

## 🚀 Running the Backend

```bash
cd backend
npm install
npm run dev
```

For full backend documentation, API references, and architecture details, see [backend/README.md](backend/README.md).
